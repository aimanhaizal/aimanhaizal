## About me

I'm a **Technology Development Researcher at MIMOS Berhad**, with a Computer Science (Data Science) background and hands-on experience integrating AWS services into IoT and data-processing systems.

My work includes **AWS IoT Core, DynamoDB, Lambda, API Gateway WebSockets, EC2, IAM and CloudWatch**, alongside Python, Linux and Docker. In an IoT energy-monitoring project, I helped resolve MQTT transmission issues and validated **100% message consistency during repeated tests**.

I'm developing further in **cloud infrastructure, infrastructure as code, CI/CD and DevOps** through hands-on projects.

- 📍 Based in Malaysia
- ☁️ AWS Certified Solutions Architect – Associate & AWS Certified Cloud Practitioner
- 🛠️ Interested in AWS Cloud Engineer, Cloud Infrastructure and DevOps roles
